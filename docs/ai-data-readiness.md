# Preparación de datos para IA

> No hay IA, chatbot, agentes ni base vectorial implementados.

El catálogo público podrá alimentar conversación; `Lead`, `Inquiry`, `Visit` y etapas, seguimiento; sesiones, eventos, campañas y gasto, análisis de marketing; ventas e históricos, BI.

Vistas futuras: `ai_public_property_catalog`, `ai_lead_context`, `ai_recent_activity`, `ai_marketing_summary`. Una IA no tendrá SQL libre: consumirá vistas o endpoints con mínimo privilegio, auditoría, consentimiento y límites de propósito. PII, comisión y notas requieren autorización explícita.
