# Retención de datos

No existe borrado automático comercial. `ANALYTICS_RETENTION_DAYS` e `INACTIVE_LEAD_RETENTION_DAYS` son opcionales; sin valor no generan candidatos. `python manage.py report_retention_candidates` sólo reporta. Cualquier eliminación requiere política aprobada, revisión de ventas/consentimientos/auditoría y procedimiento separado. Logs y backups se parametrizan en la plataforma operativa; no se presentan periodos como obligación legal.
