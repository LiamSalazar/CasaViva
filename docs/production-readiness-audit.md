## Criterios de implementación

- Se preservan Next.js + Django/DRF + PostgreSQL como monolito modular.
- El modo Pilot mantiene una sola EC2 stateful, sin Auto Scaling Group, NAT Gateway, SSH público ni pretensión de alta disponibilidad.
- RDS, CloudFront y Growth quedan codificados pero desactivados.
- Los cuatro datos legales pendientes permanecen configurables; nunca se inventan ni se publican como `PENDIENTE` o entre corchetes.
- Ninguna acción de esta implementación ejecutará `terraform apply`, cambiará DNS o creará recursos AWS.

## Línea base de pruebas

`./scripts/verify.sh` inicial: backend 167 passed/5 skipped en SQLite y 171 passed/1 skipped en PostgreSQL; checks, OpenAPI, builds, lint y typecheck pasaron. El script terminó con código 1 exclusivamente en `npm audit`: Next 16.3.1 (crítico), sharp y fast-uri (altos). `npm audit fix` actualizó el lockfile y el control posterior reportó cero vulnerabilidades.
